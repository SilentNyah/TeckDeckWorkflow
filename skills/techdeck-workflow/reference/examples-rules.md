# AGENTS.md

## Scope

この指示は `examples/` 配下の作業に適用する。

## Purpose

`examples/` には、技術資料で参照する実行可能なサンプルコードを配置する。

## Rules

* 各サンプルは、可能な限り単体でビルド・実行できる構成にする。
* 各サンプルに `README.md` を置く。
* `README.md` には、目的、前提環境、対象バージョン、実行方法、期待結果を記載する。
* スライドの説明に必要な範囲を超えて、不要に複雑な実装を追加しない。
* スライドへ掲載するコードと、完全版サンプルの内容を一致させる。
* サンプルを変更した場合は、関連する `slides/storyboard.md` とスライド内容への影響を確認する。
* 実行確認できない場合は、確認できなかった理由と範囲を記録する。
* 検証環境固有の結果を、一般仕様として断定しない。

## Verification

可能な範囲で次を実行する。

* build
* test
* sample run

実行結果は、各サンプルの `README.md` に記録する。

## Completion report

作業完了時は、次を報告する。

* 変更したサンプル
* 実行したコマンド
* 確認結果
* 関連するスライド
* 未確認事項
