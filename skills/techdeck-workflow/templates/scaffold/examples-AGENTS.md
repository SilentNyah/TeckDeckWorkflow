# AGENTS.md（`examples/` 配下）

この配下の作業は、`techdeck-workflow` スキルのサンプルコード規約に従う。

```text
{{SKILL_DIR}}/reference/examples-rules.md
```

**この配下で特に効く原則:**

* 各サンプルは単体でビルド・実行できる形にする。
* サンプルごとに `README.md` を置き、目的・前提環境・対象バージョン・実行方法・期待結果を書く。
* スライド内のコードと完全版サンプルを一致させる。
* 実行確認できない場合は、確認できなかった理由と範囲を記録する。
* 検証環境固有の結果を、一般仕様として断定しない。
